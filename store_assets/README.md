# Store asset sources

Current icon and feature graphic sources remain under icon/ and feature_graphic/.
Historical generated screenshot dumps were removed. Active reviewed upload images
belong under fastlane/metadata/android/en-US/images/phoneScreenshots and
tenInchScreenshots. The required capture set is currently incomplete.

[Asset contract](../Docs/ASSETS.md) defines canonical names/validation and the
remaining controlled-state capture workflow. Existing generation helpers are not
proof of current visual consistency or successful device captures.
